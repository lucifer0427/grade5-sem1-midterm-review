## 📖 專案特色

本專案參考微縮城市拓撲架構，為臺灣國小五年級學童量身打造。將 108 課綱五大學科期中考核心考點轉換為 3D 六角群島沙盒世界，結合學童喜愛的 **K-POP 練習生出道與打歌舞台主題**，創造沉浸式「探索 ➔ 複習 ➔ 答題 ➔ 升級」的遊戲化學習體驗！

1. **零外部 3D 模型負擔 (Zero External Assets)**：
   - 全島嶼 23 棟學科地標建築、植被與 18 隻練習生小人 100% 由 Three.js 幾何原語程序化生成，無肥大 `.gltf`/`.glb` 檔案，極速秒開，平板順暢 60 FPS。
2. **三階鷹架導學答題狀態機 (3-Tier Scaffolding)**：
   - 首次答錯觸發 **Tier 1 題眼聚焦與 50/50 干擾項排除**。
   - 二次答錯彈出 **Tier 2 核心迷思概念微卡片** 與 **Tier 3 傳送門平滑運鏡至對應島嶼建築**。
3. **高互動趣味跑島與開盲盒冒險 (Action & Exploration)**：
   - 支援第三人稱跟隨視角、WASD / 觸控點擊尋路、空白鍵立體跳躍、Shift 疾速衝刺與 B 鍵打歌熱舞。
   - 地圖散落 15 顆旋轉星光石與 5 座各島神秘幸運盲盒（金幣大獎、暴走疾風鞋、全島狂歡派對）。
4. **純原生無構建依賴 (100% Vanilla JS + Import Maps)**：
   - 無需 Node.js/Webpack 打包，推送到 GitHub Pages 即可直接線上遊玩。

## 🎮 操作說明

- **移動奔跑**：鍵盤 `W / A / S / D` 或 `方向鍵`，亦可**直接點擊地面任意六角區塊**自動尋路。
- **立體跳躍**：按下 `空白鍵 (Space)` 進行彈跳，翻越路障。
- **加速衝刺**：按住 `Shift` 鍵疾風奔馳。
- **K-POP 熱舞**：按下 `B 鍵` 或點擊右側 `💃` 按鈕，原地 360 度 Wave 打歌熱舞，引領全島歡呼！
- **進入建築挑戰**：走到建築旁按下 `E 鍵`，或點擊浮現的進入提示條。
- **全景視角**：點擊右側 `🗺️` 切換鳥瞰俯視，滑鼠左鍵旋轉拖曳、右鍵平移、滾輪縮放。
- **日夜變換**：拖曳右側日夜滑桿體驗晨曦、正午、黃昏與夜間發光舞台氛圍。

## 🚀 本地快速啟動

專案無需安裝 npm 套件或執行 build，只需任意靜態 HTTP 伺服器即可啟動：

```bash
# 使用 Python 內建伺服器啟動
python -m http.server 8080

# 或使用 Node 靜態伺服器 (若有安裝)
npx serve .
```

啟動後在瀏覽器開啟 `http://localhost:8080` 即可暢玩！
